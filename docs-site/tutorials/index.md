# Tutorials

Step-by-step walkthroughs that build real models. Each one works in the desktop app's local workspace and on a team
server.

| Tutorial | Time | You learn |
| --- | --- | --- |
| [Model a drone in 20 minutes](drone-in-20-minutes.md) | 20 min | requirements and structure as SysML v2 text, BDD, IBD with ports, a parametric endurance calculation, a state machine, satisfy and verify links, validation and commits |
| [Requirements to verification](requirements-to-verification.md) | 30 min | requirement attributes, derivation, the traceability table and matrix, test verdicts, suspect links, the Excel round trip, reviews, baselines and the V&V report |
| [Your first trade study](first-trade-study.md) | 15 min | alternatives, weighted criteria, utility curves, sensitivity, and comparing product-line configurations |
